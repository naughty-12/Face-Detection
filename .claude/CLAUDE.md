## 关键约束

- **GPU（实测）**：RTX 3060 Laptop / **6 GB 显存**（6144 MiB），驱动 581.95，CUDA 12.1
- **环境**：Windows / Python 3.12.8 / PyTorch 2.5.1+cu121
- **训练显存**：6 GB 下 `batch=8 + imgsz=640` 会超额分配（历史峰值 11.1 GB，吞吐掉到 1.7 it/s），
  建议 `batch≤4` 或 `imgsz≤512`
- **框架**：YOLOv8n-face + ultralytics；模型导出为 ONNX（FP32 + simplify）
- **数据集**：WIDER Face，训练 12,880 / 验证 3,226，沿用官方划分

## 目录结构

```
src/           库代码（被导入，不直接运行）
  paths.py     全项目唯一的路径来源
  data/ train/ eval/ deploy/
apps/vtube_bridge/   VTube Studio 表情驱动（独立应用）
configs/       配置文件           data/      数据集
artifacts/     产出（权重/图表/日志）
docs/          现状文档；archive/ 历史文档；plans/ 实施计划
tests/         测试
```

## 操作原则

- **路径必须从 `src/paths.py` 导入**，禁止任何模块用 `__file__` 自行推算项目根
  （脚本进入子包后该写法必然算错）
- 脚本一律从项目根以模块方式运行：`python -m src.<pkg>.<module>`
- 新代码归入 `src/` 下对应的功能子包，不新增顶层目录
- 保持依赖单向：`deploy → eval → train → data → paths`
- **任何指标必须标注测量口径**；口径不同的数字不得并列比较；未实测的数字不得写入文档
- 交互式脚本需提供无头开关（如 `--no-show`），保证可在脚本与 CI 中运行
- 破坏性操作前先说明影响面；每次更新同步更新文档并追加 `CHANGELOG.md` 条目
