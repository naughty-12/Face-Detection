# 高精度人脸检测 — 使用指南

基于 YOLOv8n 的高精度实时人脸检测系统。在 WIDER Face 验证集上 mAP50 = 0.664，RTX 3060 推理速度 160+ FPS。

---

## 环境要求

- **Python** 3.8+
- **PyTorch** ≥ 1.10（推荐 CUDA 12.1）
- **GPU**：RTX 3060 6GB+ 显存（CPU 亦可运行，速度较慢）
- **操作系统**：Windows / Linux / macOS

---

## 第一步：安装依赖

打开终端（PowerShell 或 CMD），进入本文件夹，执行：

```bash
pip install -r requirements.txt
```

> 如果安装 `onnxruntime-gpu` 失败，可以改装 CPU 版：`pip install onnxruntime`

---

## 第二步：选择运行模式

所有检测脚本统一入口为 `deployment/realtime_detect.py`，通过 `--input` 参数自动识别输入类型。

### 1. 实时摄像头检测

```bash
python deployment/realtime_detect.py --input 0
```

- `--input 0` 表示使用默认摄像头（多摄像头用 `1`、`2`...）
- 按 **Q 键** 退出
- 按 **S 键** 截图保存

### 2. 视频文件分析

```bash
python deployment/realtime_detect.py --input 你的视频.mp4
```

保存检测结果视频：
```bash
python deployment/realtime_detect.py --input 你的视频.mp4 --save 输出结果.mp4
```

### 3. 单张图片分析

```bash
python deployment/realtime_detect.py --input 照片.jpg
```

保存检测结果：
```bash
python deployment/realtime_detect.py --input 照片.jpg --save 结果文件夹/
```

### 4. 批量分析文件夹中的所有图片

```bash
python deployment/realtime_detect.py --input 图片文件夹/
python deployment/realtime_detect.py --input 图片文件夹/ --save 结果文件夹/
```

---

## 常用可选参数

| 参数 | 默认值 | 说明 |
|:---|:---|:---|
| `--input` | `0` | 摄像头编号 / 视频路径 / 图片路径 / 文件夹路径 |
| `--model` | `training/checkpoints/best_model_v2.pt` | 模型文件路径（支持 .pt 和 .onnx） |
| `--imgsz` | `640` | 输入图像尺寸 |
| `--conf` | `0.25` | 检测置信度阈值（0~1，越大误检越少但可能漏检） |
| `--save` | 无 | 保存路径（图片模式为文件夹，视频模式为 .mp4 文件） |

## VTube Studio 面部追踪

将人脸检测结果实时发送到 VTube Studio，驱动虚拟形象。

### 前置准备

1. 在 VTube Studio 中开启 **插件 API**（设置 → 插件 → 启动插件 API）
2. 下载 MediaPipe 面部关键点模型：

```powershell
# PowerShell 中执行：
New-Item -ItemType Directory -Force deployment/Vtube-Studio-Bridge/thirdparty/MediaPipe/models
Invoke-WebRequest -Uri "https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task" -OutFile "deployment/Vtube-Studio-Bridge/thirdparty/MediaPipe/models/face_landmarker.task"
```

### 启动桥接

```bash
# 默认连接 ws://127.0.0.1:8001，使用 0 号摄像头
python deployment/Vtube-Studio-Bridge/main.py --input 0

# 指定 VTube Studio 地址
python deployment/Vtube-Studio-Bridge/main.py --input 0 --vtshost 127.0.0.1 --vtsport 8001

# 显示 MediaPipe 面部关键点
python deployment/Vtube-Studio-Bridge/main.py --input 0 --landmarks

# 关闭 FP16 推理（CPU 用户建议关闭）
python deployment/Vtube-Studio-Bridge/main.py --input 0 --nohalf
```

> 首次连接时 VTube Studio 会弹出授权请求，同意后自动缓存 token。VTube Studio 未启动时脚本不会退出，会保持摄像头运行并每 10 秒自动重试连接。

## 常见问题

**Q: 提示 `ModuleNotFoundError`？**
A: 请先运行 `pip install -r requirements.txt` 安装依赖。

**Q: 摄像头打不开？**
A: 尝试 `--input 1` 或 `--input 2` 切换摄像头。Windows 可在"相机"应用中确认摄像头是否可用。

**Q: 检测速度很慢？**
A: 确认 PyTorch 安装了 CUDA 版本：`python -c "import torch; print(torch.cuda.is_available())"`。如果返回 `False`，请安装 CUDA 版 PyTorch。

**Q: ONNX 推理报错？**
A: 如果 CUDA 版 ONNX Runtime 不可用，安装 CPU 版：`pip uninstall onnxruntime-gpu && pip install onnxruntime`
