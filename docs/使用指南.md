# 高精度人脸检测 — 使用指南

本文面向使用者，说明如何安装、运行与排查问题。
脚本均以 YOLOv8n-face 人脸检测为核心，覆盖摄像头/视频/图片/文件夹四种输入，
并支持把检测结果接入 VTube Studio 驱动 Live2D 虚拟形象。

> **所有命令都在项目根目录执行**（脚本以模块方式运行，例如 `python -m src.deploy.detect`）。
> 指标口径与已知限制见 [`README.md`](../README.md) 与 [`项目现状与差距.md`](项目现状与差距.md)。

## 第一步：安装依赖

```bash
pip install -r requirements.txt
```

> 如果 `onnxruntime-gpu` 安装失败，可改装 CPU 版：`pip install onnxruntime`。
> 若要在离线环境安装 PyTorch，仓库内 `_wheels/` 提供了对应 CUDA 12.1 的 wheel。

---

## 第二步：选择运行模式

统一入口为 `src/deploy/detect.py`，通过 `--input` 自动识别输入类型。

### 1. 实时摄像头检测

```bash
python -m src.deploy.detect --input 0
```

- `--input 0` 表示默认摄像头（多摄像头依次用 `1`、`2` …）
- 按 **Q** 退出，按 **S** 截图保存

### 2. 视频文件分析

```bash
python -m src.deploy.detect --input 你的视频.mp4
python -m src.deploy.detect --input 你的视频.mp4 --save 输出结果.mp4   # 保存结果视频
```

输出视频沿用源文件帧率。

### 3. 单张图片分析

```bash
python -m src.deploy.detect --input 照片.jpg
python -m src.deploy.detect --input 照片.jpg --save 结果文件夹/          # 保存到文件夹
python -m src.deploy.detect --input 照片.jpg --save 结果.jpg             # 保存为单个文件
```

> ⚠️ 单图模式默认会**弹出一个结果窗口并等待你按键或关闭**。批处理、脚本或 CI 场景请加
> `--no-show`，否则命令会停在窗口上不返回。

### 4. 批量分析文件夹中的所有图片

```bash
python -m src.deploy.detect --input 图片文件夹/
python -m src.deploy.detect --input 图片文件夹/ --save 结果文件夹/
```

递归扫描文件夹，最后输出总人脸数与平均每图人脸数。

## 常用参数

| 参数 | 默认值 | 说明 |
|:---|:---|:---|
| `--input` | `0` | 摄像头编号 / 视频路径 / 图片路径 / 文件夹路径 |
| `--model` | `artifacts/checkpoints/best_model_v2.pt` | 模型路径，支持 `.pt` 与 `.onnx` |
| `--imgsz` | `640` | 输入图像尺寸 |
| `--conf` | `0.25` | 置信度阈值（越大误检越少，但可能漏检） |
| `--save` | 无 | 保存路径（图片模式为目录或文件，视频模式为 `.mp4`） |
| `--no-show` | 关闭 | 不弹结果窗口，适合脚本与批处理 |

## 性能基准测试

```bash
python -m src.deploy.benchmark
```

输出 PyTorch 与 ONNX 的延迟/FPS 与模型体积。

> ⚠️ 该脚本测的是 `model.model(dummy)` 的**裸网络前向**，不含 letterbox、解码与 NMS，
> **不是端到端帧率**；且它不打印实际生效的 ONNX ExecutionProvider，因此 ONNX 一栏的运行设备
> 目前无法确认（实测 ONNX 比 PyTorch 慢约 3 倍，可疑地慢）。

## ONNX 模型导出

```bash
python -m src.deploy.export_onnx
```

导出参数为 `dynamic=False`（静态 640×640）、`simplify=True`、`opset=12`、**`half=False`（FP32）**。

> ⚠️ **精度验证会被静默跳过**：验证函数依赖 `data/annotations/val_list.txt`。该文件不在仓库中，
> 缺失时脚本打印 `[WARN] val_list.txt not found, skipping precision validation` 后
> **直接返回"通过"**，并不会真正比对 MAE。要真正跑通验证，请先执行：
>
> ```bash
> python -m src.data.split      # 生成 train_list.txt / val_list.txt
> ```
>
> 因此"ONNX 精度损失 < 1e-4"这一说法**目前没有实测支撑**。

## VTube Studio 面部追踪

将人脸检测结果实时发送到 VTube Studio，驱动虚拟形象。

### 前置准备

1. 在 VTube Studio 中开启 **插件 API**（设置 → 插件 → 启动插件 API）。
2. MediaPipe 关键点模型 **已随仓库提供**：
   `apps/vtube_bridge/thirdparty/MediaPipe/models/face_landmarker.task`（3.76 MB），**无需下载**。

   仅在文件缺失时用下列命令恢复：

   ```powershell
   New-Item -ItemType Directory -Force apps/vtube_bridge/thirdparty/MediaPipe/models
   Invoke-WebRequest -Uri "https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task" -OutFile "apps/vtube_bridge/thirdparty/MediaPipe/models/face_landmarker.task"
   ```

### 启动桥接

```bash
# 默认连接 ws://127.0.0.1:8001，使用 0 号摄像头
python apps/vtube_bridge/main.py --input 0

# 指定 VTube Studio 地址
python apps/vtube_bridge/main.py --input 0 --vtshost 127.0.0.1 --vtsport 8001

# 在调试窗口显示 MediaPipe 关键点
python apps/vtube_bridge/main.py --input 0 --landmarks

# 关闭默认启用的 FP16 推理（CPU 用户建议关闭）
python apps/vtube_bridge/main.py --input 0 --nohalf
```

> 首次连接时 VTube Studio 会弹出授权请求，同意后自动缓存 token。VTube Studio 未启动时脚本不会退出，
> 会保持摄像头与调试窗口运行，并每 10 秒自动重试连接；连接成功后会按 VTS 返回的同名输入参数
> `min/max` 裁剪注入值。

### 常用参数

| 参数 | 默认值 | 说明 |
|:---|:---|:---|
| `--input` | `0` | 摄像头编号 |
| `--model` | `artifacts/checkpoints/best_model_v2.onnx` | YOLO 人脸框检测模型（ONNX Runtime） |
| `--vtshost` | `127.0.0.1` | VTube Studio API host |
| `--vtsport` | `8001` | VTube Studio API port |
| `--mediapipe-model` | `apps/vtube_bridge/thirdparty/MediaPipe/models/face_landmarker.task` | MediaPipe 模型路径 |
| `--mediapipe-crop-scale` | `1.45` | 将 YOLO 人脸框放大后裁剪给 MediaPipe 的比例 |
| `--landmarks` | 关闭 | 在调试窗口绘制关键点 |
| `--show-landmark-indexes` | 关闭 | 绘制关键点编号，用于校准表情映射 |
| `--nohalf` | 关闭 | 关闭桥接默认启用的 FP16 推理 |
| `--send-fps` | `30` | 向 VTube Studio 发送参数的最高频率 |
| `--smoothing` | `0.55` | 位置平滑系数，越大响应越快 |
| `--bbox-alpha` | `0.55` | 人脸框 EMA 滤波系数，越大响应越快 |
| `--bbox-window` | `5` | 人脸框中值滤波窗口大小 |
| `--hold-frames` | `3` | 检测短暂丢失时保持上一人脸框的帧数 |
| `--expression-alpha` | `0.45` | 表情参数 EMA 平滑系数 |
| `--head-pose-alpha` | `0.35` | 头部角度 EMA 平滑系数 |
| `--eye-gaze-alpha` | `0.35` | 眼球方向 EMA 平滑系数 |

Windows 下也可直接双击 `apps/vtube_bridge/run_gui.bat` 启动（使用 PATH 中的 `pythonw`）。

## 训练

```bash
python -m src.train.train        # v1 基线 100 epoch + v2 微调 30 epoch
python -m src.train.resume       # 断点续训
tensorboard --logdir artifacts/checkpoints --port 6006
```

> ⚠️ 本机为 **6 GB 显存**，`batch=8 + imgsz=640` 会超额分配（历史日志峰值 11.1 GB）并导致吞吐骤降。
> 建议在 `configs/model.yaml` 中把 `batch_size` 降到 4，或把 `imgsz` 降到 512。

## 常见问题

**Q: 提示 `ModuleNotFoundError`？**
A: 先执行 `pip install -r requirements.txt`。

**Q: 单图检测跑完不返回 / 每次都要手动关窗口？**
A: 单图模式默认会弹出结果窗口并等待关闭。加 `--no-show` 即可。

**Q: 摄像头打不开？**
A: 换 `--input 1` 或 `--input 2`。Windows 下可在"相机"应用确认设备可用。

**Q: 检测速度很慢？**
A: 确认 PyTorch 装了 CUDA 版本：`python -c "import torch; print(torch.cuda.is_available())"`。
   若为 `False`，需安装 CUDA 版 PyTorch。

**Q: ONNX 推理报错？**
A: `pip uninstall onnxruntime-gpu && pip install onnxruntime`（改用 CPU 版）。

**Q: `python src/deploy/detect.py` 报导入错误？**
A: 脚本需以模块方式运行。请用 `python -m src.deploy.detect`，并在项目根目录执行。

**Q: 训练时显存不足或速度突然变慢？**
A: 6 GB 显存下 `batch=8` 已超额分配。把 `configs/model.yaml` 的 `batch_size` 降到 4，
   或 `imgsz` 降到 512。
