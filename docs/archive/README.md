## 为什么保留

这个项目按"先跑通可用的原型，再把文档校正为可信状态"的顺序推进。这两份文档记录了当初的
目标、假设与取舍，是**逐项核对实现差距、补齐缺漏的输入清单**，因此不删除、不改写。

它们同时是两份需要被明确标注的历史包袱：

- 文档里的**指标目标**（Hard 子集 mAP ≥ 0.76）与**实际口径**（全验证集 mAP50 = 0.664）不可直接比较；
- 文档里的**目录结构**（`data/ dataset/ model/ training/ evaluation/ deployment/`）已被重组为
  `src/ apps/ configs/ data/ artifacts/`；
- 文档里的**"外六内一 / 六人分工"**表述不反映实际情况，本项目由一人独立完成；
- 文档里的**硬件假设**（RTX 3060 12GB）与实际机型（RTX 3060 Laptop 6GB）不符。
